# Marius Comper

Editor and builder of public-facing research, data and interactive web projects.

## Selected public data projects

- [Puntea universală de identificatori administrativi](https://github.com/mariuscomper/puntea-administrativa) — Romanian administrative data linking SIRUTA, CUI/CIF, postal codes, Wikidata QIDs, population and coordinates. [Live tool](https://mariuscomper.uk/puntea-administrativa/)
- [Arhiva unificată GTFS a transportului feroviar din România](https://github.com/mariuscomper/gtfs-romania-feroviar) — static passenger-rail timetable data for seven operators, with GTFS, SQLite and GeoJSON downloads. [Live explorer](https://mariuscomper.uk/gtfs-feroviar/)

Both projects are documented with reproducible snapshot details, source notes, machine-readable links and explicit limitations.
